```typescript
    { media: '(prefers-color-scheme: dark)', color: '#0f172a' },
  ],
  // ... other metadata
};
```

## How Next.js Serves Favicons

### Automatic Detection

Next.js 14 automatically detects and serves these files from the `app` directory:

1. **`app/favicon.ico`** → Served at `/favicon.ico`
   - Traditional favicon
   - Works in all browsers
   - Multi-size ICO format

2. **`app/icon.png`** → Served at `/icon.png`
   - Modern icon format
   - Used by PWAs and modern browsers
   - 192x192 pixels

3. **`app/apple-icon.png`** → Served at `/apple-icon.png`
   - Apple touch icon
   - Used by iOS devices when saving to home screen
   - 180x180 pixels

4. **`app/manifest.ts`** → Served at `/manifest.webmanifest`
   - PWA manifest
   - Lists all icon sizes
   - Defines app behavior when installed

### Generated HTML Tags

Next.js automatically adds these tags to `<head>`:

```html
<!-- Favicon -->
<link rel="icon" href="/favicon.ico" sizes="any" />
<link rel="icon" href="/icon.png" type="image/png" sizes="192x192" />
<link rel="icon" href="/favicons/favicon.svg" type="image/svg+xml" />

<!-- Apple Touch Icon -->
<link rel="apple-touch-icon" href="/apple-icon.png" sizes="180x180" />

<!-- PWA Manifest -->
<link rel="manifest" href="/manifest.webmanifest" />

<!-- Theme Color -->
<meta name="theme-color" content="#0f172a" media="(prefers-color-scheme: light)" />
<meta name="theme-color" content="#0f172a" media="(prefers-color-scheme: dark)" />

<!-- Apple Web App -->
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="default" />
<meta name="apple-mobile-web-app-title" content="Schema Validator" />
```

## Troubleshooting

### Favicon Not Appearing

**Issue:** Favicon doesn't show in browser tab

**Solutions:**
1. **Hard refresh:** Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. **Clear cache:** Browser settings → Clear browsing data
3. **Check file exists:** Visit `/favicon.ico` directly
4. **Rebuild:** `npm run build` to regenerate
5. **Check console:** Look for 404 errors in DevTools

### Wrong Favicon Showing

**Issue:** Old favicon still appearing

**Cause:** Browser caching

**Solutions:**
1. Clear browser cache completely
2. Try incognito/private mode
3. Wait 5-10 minutes for cache expiration
4. Force reload with Ctrl+Shift+R

### PWA Icon Issues

**Issue:** Wrong icon when installed as PWA

**Solutions:**
1. **Check manifest:** Visit `/manifest.webmanifest`
2. **Verify icon paths:** Ensure `/favicons/` directory exists
3. **Rebuild manifest:** Delete `.next` and rebuild
4. **Uninstall PWA:** Remove old installation and reinstall

### Missing iOS Icon

**Issue:** Generic icon on iOS home screen

**Solutions:**
1. **Check apple-icon.png exists:** Visit `/apple-icon.png`
2. **Verify size:** Should be 180×180 pixels
3. **Check metadata:** Ensure `apple` icons configured
4. **Clear iOS cache:** Delete and re-add to home screen

## Maintenance

### Updating Favicon

**When to update:**
- Rebranding
- Logo changes
- Color scheme updates
- Design improvements

**How to update:**

1. **Generate new favicons:**
   - Use [favicon.io](https://favicon.io) or similar tool
   - Export all sizes

2. **Replace files:**
   ```bash
   # Backup old favicons
   mv public/favicons public/favicons.backup

   # Copy new files
   cp new-favicons/*.png public/favicons/
   cp new-favicons/favicon.svg public/favicons/

   # Update app directory
   cp new-favicons/favicon.ico app/
   cp new-favicons/icon-192x192.png app/icon.png
   cp new-favicons/icon-180x180.png app/apple-icon.png
   ```

3. **Update manifest (if needed):**
   - Edit `app/manifest.ts`
   - Update theme colors
   - Rebuild

4. **Test:**
   ```bash
   npm run build
   npm start
   # Visit http://localhost:3000
   # Hard refresh (Ctrl+Shift+R)
   ```

5. **Deploy:**
   ```bash
   vercel --prod
   ```
